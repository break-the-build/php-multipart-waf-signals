================ 2. What the trace means (reference: ext/session/session.c pointers) ================
  CACHE P1   = pointer cached into table T_old (bytes_processed bucket)
  SEPDONE    = END-event SEPARATE_ARRAY dup: progress->data now owns T_new
  STALE-WRITE = cached pointer WRITES into T_old — detached (no owner among live state)
  TI destroy = T_old (already written stale) is destroyed by track_init
